# Fichamentos

Uma pasta ou arquivo por autor/obra que a Mallu decide guardar como base teórica de longo
prazo (o cérebro geral do PAAPS). Régua estreita: só o que ela já discute há tempo ou pede
explicitamente pra guardar aqui, nunca todo material que passa por `arquivos/`.

O `../README.md` (base teórica destilada que a Tecelã lê) cresce a partir do que entra
aqui: fichamento inteiro mora neste diretório, a destilação em movimento de raciocínio
utilizável vai pro README.

Alimentado pela skill `.claude/skills/segundo-cerebro-paaps/SKILL.md`, mas a decisão de
promover algo pra cá é sempre da Mallu, nunca automática.
