# Frente 3: Crescimento no Instagram

Ganhar seguidores em @paaps.brasil e @psimalluvasconcellos, e afunilar esse público para
a Comunidade ECOA.

## O que precisa existir aqui

- `fluxos/` : JSONs do n8n para coleta e análise de desempenho (o agente Sentinela já
  faz o embrião disso via Windsor AI).
- `funil-para-ecoa.md` : documento do funil. Que tipo de post leva para onde, qual
  chamada convida para a ECOA, qual é o caminho do seguidor novo até entrar na
  comunidade.

## Cuidado principal

termos do Instagram e derruba a conta. O que se automatiza aqui é **análise e produção**;
a interação com pessoas continua humana.

Relatórios com dados de seguidores identificáveis não entram no repositório.
