# Aprendizado — Crítico de Design PAAPS

## Situação: peça inteira em HTML/Chrome headless, não Canva

**Quando acontece:** a partir de 31/08/2026, o caminho oficial de montagem de carrossel é
HTML/CSS fotografado por Chrome headless, não Canva. Este agente foi escrito quando Canva
era o único caminho.

**O que muda no seu critério:** ao avaliar uma peça, primeiro identifique qual pipeline a
gerou. Para peça HTML, os anti-padrões relevantes incluem os específicos do pipeline (véu de
legibilidade em gradiente ou em cor de marca em vez de preto sólido; textura vazando da
própria caixa para a foto ou para textura vizinha; texto estourando a borda por não ter sido
checado na imagem renderizada) — nenhum desses existe no vocabulário de erro do Canva.

Ver `insumos-compartilhados/nucleo-comum/anatomia-do-carrossel-aprovado.md` para a peça de
referência e a lista completa das 7 rodadas de correção que já aconteceram nesse pipeline.
