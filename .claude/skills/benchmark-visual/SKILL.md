# Benchmark Visual Comparativo — PAAPS

Framework consolidado por Mallu (jun/2026), antes colado manualmente a cada uso.

## Regras

1. Navegação real via MCP de navegador com screenshots como evidência — nunca WebFetch.
2. Antes de benchmark de posicionamento, visitar criticamente as referências obrigatórias
   do CLAUDE.md raiz: yunusns.com, agendapublica.org.br, dengo.com.
3. Relatório publicado no Notion (subpágina da página de operações), formato das existentes.
4. Mesma profundidade do primeiro ao último item analisado.

## Processo

1. **Exemplo-base**: contexto (produto, página, componente), o que chama atenção
   visualmente, objetivo da interface, hierarquia visual, tom de voz, padrões de
   persuasão presentes.
2. **Buscar 3 a 5 referências comparáveis** — concorrentes diretos ou indiretos,
   nacionais e internacionais. Quando fizer sentido, incluir premiadas (Awwwards, FWA,
   Webby, Red Dot, iF Design) e citar o prêmio.
3. **Para cada referência**: padrões visuais (layout, hierarquia, cores, tipografia,
   ícones, ilustrações, microinterações), soluções de usabilidade (fluxos, menus,
   feedback, acessibilidade), diferenciais e inovações, crítica construtiva
   (limitações de acessibilidade ou performance).
4. **Síntese**: o que pode ser adaptado ao contexto PAAPS, o que a referência faz melhor
   que a média, cuidados de performance/acessibilidade, lista priorizada de inspirações
   aplicáveis.

## Entrega

Formato estruturado (tabela ou tópicos), linguagem clara e crítica. Publicar no Notion
e informar o link.
