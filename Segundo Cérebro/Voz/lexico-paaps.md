# O léxico da PAAPS

**A linguagem é o produto visível da epistemologia.** Cada palavra escolhida revela o que a
PAAPS acredita; cada palavra recusada revela o que ela recusa acreditar.

| Usa | No lugar de |
|---|---|
| adoecimento sistêmico | burnout do indivíduo |
| diagnóstico situado | avaliação padronizada |
| capacidade instalada | resultado entregue |
| território | contexto, ambiente |
| potência | produtividade |
| autonomia institucional | dependência de fornecedor |
| linha de frente | usuário, cliente interno |
| sistema relacional, dinâmica institucional | clima organizacional |
| cuidar de quem cuida · tecnologia social · intervenção · dispositivo · elaboração coletiva | |

## O que a PAAPS evita, e por quê

Bem-estar isolado, sem crítica · mindfulness e resiliência como solução · felicidade
organizacional · clima organizacional sem problematizar o conceito · colaboradores felizes
· jornada do colaborador · engajamento sem crítica de contexto · soluções inovadoras ·
resultados extraordinários · transformar vidas (messiânico) · parceiro estratégico ·
pessoas são o maior ativo.

Duas famílias, dois motivos: a primeira joga a peça para a categoria de bem-estar de
mercado; a segunda é clichê de consultoria, que não diz nada.
